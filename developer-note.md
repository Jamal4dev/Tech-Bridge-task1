I designed a clean, responsive homepage for TechBridge using the colors in its logo. The page introduces the organization, presents its Data Analytics and Web Development programs, and describes the 30-day practical internship. I used semantic HTML to organize the content and CSS Grid and media queries to adapt the layout for desktop, tablet, and mobile. I learned how page structure, navigation links, and responsive styling work together, and making the page easy to use on smaller screens was my main challenge.
