I designed a clean, responsive homepage for TechBridge using colors from it's logo. I faced a challenge making the page work on smaller screens while keeping the program cards aligned and their content well-spaced. CSS Grid stretches the cards to a consistent height, while auto-fit and minmax() let the columns adapt to the available space. I used object-fit: cover to fit the logo into it's display area without stretching, and clamp() to scale the hero text fluidly across screen sizes. I learned how semantic HTML, navigation links, and responsive styling work together to create an accessible user experience.
